# 🌟 SpeakFlow 機能仕様・学習機能ガイド (Features Guide)

SpeakFlow は、**Google Gemini API** を活用して実践的なスピーキング・リスニング・瞬発力を総合的に鍛える Web 英会話トレーニングアプリケーションです。  
本書では、ユーザーおよび学習者目線における各学習機能の詳細な仕様、学習フロー、および活用方法を解説します。

## 1. 3つのコアトレーニングと学習アプローチ

英語を「知っている」状態から「とっさに話せる」状態へ引き上げるため、SpeakFlow は以下の3つの補完的なトレーニングと専任 AI コーチを提供しています。

| トレーニング | 目的・鍛えられる力 | 特徴 |
| :--- | :--- | :--- |
| **AI 英会話ロールプレイ** | 実践対話力・文脈理解・総合コミュニケーション | 多彩なシチュエーション、最新ニュース会話、終了後の総合診断レポート |
| **瞬間英作文 (Blitz)** | 瞬発力・構文の自動化・スピーキング反射神経 | 日本語提示から3〜7秒のタイムアタック、Gemini による即時自動添削 |
| **シャドーイング** | リスニング・発音・イントネーション・リズム感 | ネイティブ音声への追従音読、Web Speech による発話一致率スコアリング |
| **常駐 AI コーチ** | 疑問の即時解消・学習アドバイス・表現の深掘り | 全画面どこからでも呼び出し可能、画面に応じたコンテキスト自動認識 |

## 2. 🎭 1. AI 英会話ロールプレイ ＆ 総合診断 (Conversation Coach)

### 2.1. 概要
カフェでの注文や空港での手続きといった日常会話から、ビジネス交渉や就職面接まで、リアルなシチュエーションを選んで AI パートナーと音声・テキストで対話するトレーニングです。

### 2.2. シチュエーション ＆ 難易度選択
- **プリセットシチュエーション**:
  - `Ordering at a Cafe`（カフェでの注文）
  - `Checking in at an Airport`（空港チェックイン）
  - `Hotel Reservation & Inquiries`（ホテルの予約・問い合わせ）
  - `Job Interview`（英語での就職面接）
  - `Business Meeting Negotiation`（ビジネス商談・プレゼン）
  - `Casual Free Talk`（フリートーク）
- **4段階の難易度レベル**:
  - **Beginner**: 短く平易な単語と明確な文法で対話。
  - **Intermediate**: 自然な日常会話スピードと表現で対話。
  - **Advanced**: 抽象度の高い語彙や慣用句、複雑な構文を含む対話。
  - **Casual**: 親しみやすいスラングや日常の口語表現を活用。
- **目標設定 (Goals)**:
  - 各シチュエーションごとに「注文を完了する」「要望を正確に伝える」などの具体的ゴールが提示され、学習の到達度を意識しながら進められます。

### 2.3. 最新ニュース AI シナリオ生成 (Google Search Grounding)
- テクノロジー、ビジネス、サイエンス、国際情勢などの最新トレンドを AI が Google 検索を通じて取得。
- 選択した難易度に合わせて、「いま世界で話題のニュース」について議論する生きた対話シナリオをリアルタイムに自動生成します。

### 2.4. リアルタイム音声対話 ＆ 即時学習サポート
- **Web Speech API 音声認識 ＆ TTS 自動再生**:
  - マイクボタンを押して英語を話すだけで文字起こしされ、AI の返答はネイティブ音声で自然に読み上げられます。
- **Better Phrasing (より自然な表現)**:
  - ユーザーの発話直後、「意味は通じるが、ネイティブならこう言う」という改善表現とワンポイント解説をメッセージ下部にリアルタイム表示。
- **日本語訳トグル**:
  - ユーザーの発言および AI の発言の両方を、ワンタップで日本語訳表示に切り替え可能。
- **3段階 AI 応答ヒント**:
  - 返答に困った際、「Easy（簡単）」「Medium（標準）」「Advanced（高度）」の3つの回答候補を AI が提示し、スムーズな対話をサポート。

### 2.5. セッション終了時の総合診断レポート
会話を終了すると、Gemini AI がセッション全体を多角的に分析したレポートを即座に生成します：
- **総合スコア (100点満点)**: 文法、語彙、流暢さ、対話の適切さを総合評価。
- **カテゴリー別フィードバック**: 良かった点（Strengths）と改善が必要な点（Areas for Improvement）の具体的な助言。
- **重要キーフレーズ集**: 会話内で登場した、覚えておくべき表現を一覧化。
- **ゴール達成判定**: 設定された目標を達成できたかを客観的に判定。

## 3. ⚡ 2. 瞬間英作文 ＆ パターンプラクティス (Instant Oral Blitz)

### 3.1. 概要
日本語の短文を見て、頭の中で英訳を組み立てて即座に声に出す「瞬間英作文」トレーニングです。文法知識を「考え込まずに反射的に口から出る」レベルまで高めます。

### 3.2. 柔軟なタイマー設定（瞬発力特訓）
- **3秒 (Fast)**: 超高速スピーキング。考え込む隙を与えず、反射神経を極限まで鍛える。
- **5秒 (Standard)**: 標準的な即答テンポ。リズムよくパターンプラクティスをこなす。
- **7秒 (Relaxed)**: 初級者向け。構文を落ち着いて整理してから発話する。
- **制限なし (No Limit)**: 時間を気にせず自分のペースでじっくり思考する。

### 3.3. 多彩な出題カテゴリ ＆ AI カスタムお題生成
- **体系的カリキュラム（基礎構文パターン 10セット・計100問）**:
  - 中学・高校レベルの最重要英文法（be動詞、一般動詞、過去形、進行形、未来表現、助動詞、比較、不定詞・動名詞、受動態、現在完了）を網羅した各10問の集中トレーニング。
  - 各構文の型（パターンプラクティス）を身体に染み込ませる反復ドリル。
- **シチュエーション即レス**:
  - ビジネスミーティングでの即答、旅行トラブル、日常リアクションなど、実用的なシーン別の即答練習。
- **AI カスタムお題自動生成**:
  - 入力した任意のキーワード・テーマから Gemini AI がオリジナル問題を瞬時に10問生成。
  - サイコロボタンによる「おまかせ自動選定」や人気トピックチップにより、いつでも新しいテーマで無限に練習可能。

### 3.4. Gemini AI によるリアルタイム発話自動添削
- ユーザーの発話（音声またはテキスト）を Gemini AI がリアルタイムに自動解析。
- **合格・不合格判定**: 単なる文字列一致ではなく、「意味が正確に通じているか」「文法的に自然か」を総合判定。
- **詳細フィードバック**:
  - 正解例との比較
  - ユーザーの発話を活かした改善案（More Natural Phrasing）
  - つまずきやすいポイントの文法アドバイス
- **テキスト手動修正機能**:
  - 音声認識の聞き間違いが生じた場合でも、ワンタップでテキストを修正して即座に AI 再評価を実行可能。

### 3.5. セッション振り返りサマリー
10問のセッション完了時に、正解率、平均回答スピード（秒）、および各問題の AI 添削結果を一覧で振り返ることができます。

## 4. 🎧 3. シャドーイング・スタジオ (Shadowing Studio)

### 4.1. 概要
ネイティブスピーカーの音声を聞きながら、わずかに遅れて影（shadow）のように同時に発話するトレーニングです。英語特有のリズム、イントネーション、音声変化（リエゾンやリダクション）を体得します。

### 4.2. スクリプト教材 ＆ カスタム入力
- **カテゴリ別プリセット教材**:
  - ビジネスプレゼンテーション、日常英会話、ニュース解説、有名スピーチなど。
  - レベルに応じた多様な英文スクリプトを用意。
- **カスタムスクリプト入力**:
  - 学習中の外部教材やニュース記事など、手持ちの英文テキストを自由に貼り付けて練習可能。

### 4.3. 再生コントロール ＆ 音声設定
- **5段階スピード調整**:
  - `0.5x`, `0.75x`, `1.0x`, `1.25x`, `1.5x` の速度調整に対応。
  - 苦手な箇所はスロースピードで発音の確認、慣れてきたらナチュラルスピード以上で負荷をかけた練習が可能。

### 4.4. 音声認識による精度スコアリング
- マイクに向かってシャドーイングした音声を Web Speech API で認識。
- 元の英文スクリプトとユーザーの発話テキストを単語単位で照合し、**一致率・類似度（%）** をリアルタイム算出。
- どの単語を正確に発話できたか、聞き落とした単語はどれかを可視化します。

## 5. 💡 4. 全画面常駐型 AI コーチングアシスタント (Floating Coach Widget)

### 5.1. 概要
学習中に生じた疑問や不安をその場で解消するため、画面右下に常に専任 AI コーチ（フローティングボタン）が待機しています。いつでも日本語で気軽に質問できます。

### 5.2. シチュエーション連動 ＆ リアルタイム学習コンテキスト認識 (CoachContext)
AI コーチはグローバルな `CoachContext` と連動し、ユーザーが現在開いている画面やリアルタイムの学習状況（問題文・回答内容・合否判定）を自動的に把握しています：

- **ホーム / セレクター画面**:
  - 「初級者にはどのトレーニングから始めるのが良い？」「おすすめのシチュエーションは？」など、学習計画や機能選びを気軽に相談。
- **ロールプレイ英会話中**:
  - 現在の会話シチュエーション、直前の AI 発言、ユーザーの発言内容を把握。
  - 「相手が言った表現のニュアンスは？」「この場面でのマナーや定番の返答フレーズは？」など、直前の対話文脈を踏まえた実践的アドバイスを提示。
- **瞬間英作文セッション中（リアルタイム回答同期）**:
  - 出題中の日本文・模範解答に加え、**ユーザーの音声/テキスト回答内容および AI 合否判定（合格・不合格）** をリアルタイムに把握。
  - 上部に「出題中コンテキストバナー」が表示され、「なぜ不合格だった？」「他の自然な言い回しは？」「文法のポイントを教えて」などの状況適応型クイック質問チップからワンタップで質問可能。
- **シャドーイング特訓中**:
  - 選択中の英文スクリプト、音声再生速度、ユーザーの認識テキスト、および発話一致率（スコア）を把握。
  - 「この文の文法構造を教えて」「発音のつながり（リエゾンやリダクション）はどう意識すべき？」などを詳しく解説。

## 6. 📱 5. UI ＆ ユーザー体験 (User Experience)

### 6.1. モバイル最適化レスポンシブ設計
- スマートフォン、タブレット、PC のすべての画面サイズに最適化。
- モバイル端末では固定ボトムナビゲーションを配置し、片手操作で「ロールプレイ ⇆ シャドーイング ⇆ 瞬間英作文」を素早く切り替え可能。

### 6.2. 安全なローカル API Key 管理
- Google Gemini API Key はユーザー自身のブラウザ（`LocalStorage`）にのみ安全に保存されます。
- バックエンドサーバー等へ Key が送信・保存されることは一切ありません。

### 6.3. オフライン・フォールバック対応 (Graceful Degradation)
- AWS バックエンド（DynamoDB）との接続が未設定またはオフラインの場合でも、アプリ内蔵のローカルシナリオデータへ自動フォールバック。
- 外部環境に左右されず、いつでもトレーニングを中断なく継続できます。
